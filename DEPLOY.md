# Deployment runbook — TJT

Короткий конечный список, что нужно, чтобы **сайт стал живым в интернете** и
**начал приносить деньги**. Не Vercel — обычный сервер (VPS) с Docker.

---

## Часть A — Технический запуск (реально несколько часов)

Сайт уже собирается в прод без ошибок. Нужно только развернуть.

### 1. Сервер
Любой VPS с Docker (Hetzner / Timeweb / Selectel — 2 vCPU / 2 GB достаточно).

### 2. Секреты окружения
Скопируй `.env.example` → `.env` в корне и заполни:

| Переменная | Зачем | Обязательно |
|---|---|---|
| `ADMIN_PASSWORD` | вход в `/admin/dashboard` | да |
| `ADMIN_SESSION_SECRET` | подпись сессий (`openssl rand -hex 32`) | да |
| `NEXT_PUBLIC_SITE_URL` | канонические URL, sitemap, SEO | да |
| `ADMIN_API_SECRET` | токен для публикации статей ИИ-фабрикой | если нужна генерация |
| `COINGECKO_API_KEY` | живые котировки | опционально |
| `OPENAI_API_KEY` | без него ИИ-фабрика в Demo Mode | если нужна генерация |

### 3. Сборка и запуск
```bash
docker build -t tjt .
docker run -d --name tjt -p 3000:3000 --env-file .env \
  -v $(pwd)/config.json:/app/frontend/config.json \
  -v $(pwd)/sys_registry.json:/app/frontend/sys_registry.json \
  tjt
```
> ⚠️ **Важно:** два volume обязательны. В рантайме сайт **пишет** в
> `config.json` (контент) и `sys_registry.json` (клики/метрики). Без монтирования
> эти данные пропадут при перезапуске контейнера.

### 4. Домен + HTTPS
Nginx/Caddy как реверс-прокси на `127.0.0.1:3000`, домен, сертификат Let's Encrypt.
Прописать домен в `NEXT_PUBLIC_SITE_URL`.

### 5. Проверка
- Главная, `/en` и `/ru`, `/news`, `/offers`, `/reviews` открываются.
- `/admin/login` пускает по паролю; дашборд виден.
- Клик по офферу учитывается в дашборде.

**Итог части A: сайт живой.** Это чисто техническая работа, блокеров нет.

## Часть B — Как это РЕАЛЬНО начнёт зарабатывать (честно)

> Это главное, и об этом нельзя молчать.

Сейчас в `config.json` реф-ссылки выглядят так:
`https://app.aave.com/?ref=tjt`, `https://stake.lido.fi/?ref=tjt` и т.д. —
это официальные адреса протоколов с дописанным `?ref=tjt`.

**Проблема:** Aave, Lido, Compound, Morpho и большинство DeFi-протоколов
**не имеют реферальных/CPA-программ**, которые платят за параметр `?ref=`.
То есть в текущем виде такие ссылки приносят **$0** — это не баг в коде,
а несуществующая партнёрская связь за ссылкой.

**Что действительно платит (выбрать модель):**

1. **Реферальные программы бирж (CEX)** — Binance, Bybit, OKX, Bitget.
   Реально платят 20-50% комиссии, есть партнёрские кабинеты с трекинг-ссылками,
   работают на RU-аудиторию. **Самый быстрый путь к реальному доходу.**
2. **Крипто рекламные сети** — Coinzilla, Bitmedia и т.п. Платят за показы/клики,
   нужен трафик.
3. **Партнёрки через CPA-сети** — искать реальные офферы с выплатами.

**Что нужно от тебя (это НЕ код, это регистрация):**
- Завести аккаунт хотя бы в одной реальной партнёрке (реалистично — CEX-реферал).
- Получить настоящие трекинг-ссылки.
- Я заменю `referral_url` в офферах на реальные — 15 минут работы.

**Честный вывод по «когда заработаем»:**
- **Технически live:** дни (часть A).
- **Первые реальные деньги:** зависит от одного действия — подключить реальную
  партнёрскую программу. Продукт (сложное) готов; монетизация (простое, но твоё)
  — 30 минут регистрации, а не месяцы кода.
